About

I am a Web Developer Intern at Redynox, learning how front-end pages connect to back-end systems.

What I am learning

This internship focuses on two things: building clean, responsive pages, and understanding how a browser sends information to a server. This website is the result of both tasks.

Skills used

  • HTML5
  • CSS3
  • Flexbox
  • Media queries
  • JavaScript
  • Form validation
  • Browser DevTools

How the site is built

Structure

Each page uses header, nav, main, section, and footer elements, with one h1 per page.

Styling

One shared stylesheet defines colours, spacing, and type as CSS variables, so every page stays consistent.

Responsiveness

Flexbox lets content wrap naturally. A media query at 600px stacks the navigation and makes buttons full width on phones.
